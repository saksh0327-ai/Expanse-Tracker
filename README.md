Expense Tracker

Project Description

Expense Tracker is a simple web application that helps users manage their income and expenses. It calculates total income, total expenses, and the remaining balance.

Features

- Add income transactions.
- Add expense transactions.
- Choose transaction categories.
- View transaction history.
- Delete transactions.
- Automatically calculate income, expenses, and balance.
- Save transactions using browser local storage.

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone this project.
2. Open the "Expense-Tracker" folder.
3. Double-click "index.html" to launch the application in a web browser.
